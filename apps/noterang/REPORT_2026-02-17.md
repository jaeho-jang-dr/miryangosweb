### 4.2 상세 변경

#### auto_login.py — 에러 핸들링 개선
```python
# Before (bare except)
except:
    pass

# After (명시적 예외 + 로깅)
except Exception:
    print("  ⚠️ TOTP 입력 필드를 찾을 수 없습니다")
```

#### browser.py — 신규 메서드 `add_source_via_search(query)`
- 웹 검색을 통한 소스 자동 추가
- 흐름: 소스 버튼 → 검색 옵션 → 쿼리 입력 → 결과 선택 → 확인
- 한국어 UI 지원, 전체 에러 처리, `bool` 반환

#### browser.py — 버그 픽스 2건
1. 디버그 스크린샷 경로: CWD → `download_dir`로 수정
2. 메서드 호출: `check_slides_ready()` → `get_slide_status()` 리팩토링

#### config.py — 슬라이드 타임아웃
```python
timeout_slides: int = 300  →  600  # 5분 → 10분 (300은 부족!)
```
